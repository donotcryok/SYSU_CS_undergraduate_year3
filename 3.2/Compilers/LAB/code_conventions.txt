实验课必备的 Java 代码规范核心点在接下来的实验中，我要求你的代码严格遵循以下规则：命名规范 (Naming Conventions)类 (Classes)： 类名必须是名词，采用混合大小写，并且每个内部单词的首字母都要大写（例如 class Raster） 。方法 (Methods)： 方法名应当是动词，采用混合大小写，第一个单词首字母小写，后续内部单词首字母大写（例如 runFast()） 。变量 (Variables)： 变量名的首字母必须小写，且应简短并富有意义，旨在向观察者表明其使用意图（例如 myWidth） 。常量 (Constants)： 类常量的名称应该全部大写，单词之间使用下划线分隔（例如 MAX_WIDTH） 。文件结构与排版单文件单类： 每个Java源文件只应包含一个公共类（public class）或接口 。控制文件长度： 长度超过2000行的文件会显得非常笨重，应尽量避免 。缩进与行宽： 缩进应统一使用4个空格作为单位 。为了兼容不同的终端和工具，应避免单行代码超过80个字符 。控制结构与作用域强制大括号： 当语句是控制结构（如 if-else 或 for）的一部分时，即使它是单行语句，也必须使用大括号包围 。这使得将来添加语句变得更容易，且不会因为忘记添加大括号而意外引入Bug 。避免随意公开： 除非有充分的理由，否则不要将实例或类变量设为 public 。注释 (Comments)Java程序支持两种注释：实现注释（由 /*...*/ 和 // 界定）以及文档注释（由 /**...*/ 界定） 。文档注释用于从独立于实现的视角来描述代码的规范 。它们可以通过 javadoc 工具提取生成HTML文件，供不直接接触源码的开发者阅读
