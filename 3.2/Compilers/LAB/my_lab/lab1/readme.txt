二、 实验收获与体会
-------------------
1. 从“面向过程”到“面相对象”的思维跨越：
以前遇到分段计算问题，我往往会本能地写出一长串阶梯式的 if-else 语句。而在本次实验中，为了应对未来可能的“税法变动”（如起征点和税率级数的调整），我将具体的“税率条目”抽象为了独立的 TaxRateItem 实体类，并在计算器中通过 List 将它们组合起来。

2. 架构分层带来的彻底解耦：
实验中，我划分了类的职责，实践了分层架构思想。负责控制台 I/O 交互的 TaxApp、负责核心计税算法的 TaxCalculator 和负责数据承载的 TaxRateItem 。这种分层设计不仅让代码结构清晰，还为未来的功能扩展提供了便利的接口和良好的可维护性。

3. 健壮性与自动化回归测试的工程实践：
通过在用户输入层引入 try-catch 异常拦截机制，程序在面对非法输入时能够提示并恢复，避免了崩溃。此外，我还编写了 regression_test.bat 批处理脚本，结合包含边界值（如刚好等于起征点）、非法值等情况的测试用例文件，实现了自动化的回归测试。这让我感受到了自动化测试的重要保障作用。

4. 编码规范与文档习惯的养成：
实验中，我严格遵循了 Sun/Oracle 的 Java 编码规范，并利用 javadoc 工具根据源代码注释一键生成了专业的 HTML 结构文档。这让我体会到了正规工业级软件开发的严谨性。
