

### 一、 题目翻译

给定以下文法：
$S \to ( L ) \mid a$
$L \to L , S \mid S$

* 消除该文法中的左递归。
* 画出该文法的状态转换图。
* 编写一个递归下降预测分析器。
* 指出输入句子 `(a, (a, a))` 的过程调用序列。

---

### 二、 详细解答

#### 1. 消除文法中的左递归

**分析：**
观察文法，$S$ 产生式没有左递归。$L$ 的产生式 $L \to L , S \mid S$ 存在**直接左递归**。
根据消除直接左递归的通用公式：对于 $A \to A\alpha \mid \beta$，可以转换为 $A \to \beta A'$ 和 $A' \to \alpha A' \mid \varepsilon$。
在这里，令 $A = L$，$ \alpha = , S $，$ \beta = S $。

**解答：**
消除左递归后的等价文法如下：

$$
S \to ( L ) \mid a
$$

$$
L \to S L'
$$

$$
L' \to , S L' \mid \varepsilon
$$

---

#### 2. 画出该文法的状态转换图

**分析：**
为了构造递归下降分析器，我们需要为每一个非终结符（$S$, $L$, $L'$）画出状态转换图。终结符作为边上的条件，非终结符作为调用子图的处理。

**解答（文字描述与结构表示）：**

* **S 的转换图：**
* 分支1：`起始` $\xrightarrow{\text{ ' ( ' }}$ `节点1` $\xrightarrow{\text{ 调用 L }}$ `节点2` $\xrightarrow{\text{ ' ) ' }}$ `接受`
* 分支2：`起始` $\xrightarrow{\text{ ' a ' }}$ `接受`
* **L 的转换图：**
* 单一路径：`起始` $\xrightarrow{\text{ 调用 S }}$ `节点1` $\xrightarrow{\text{ 调用 L' }}$ `接受`
* **L' 的转换图：**
* 分支1：`起始` $\xrightarrow{\text{ ' , ' }}$ `节点1` $\xrightarrow{\text{ 调用 S }}$ `节点2` $\xrightarrow{\text{ 调用 L' }}$ `接受`
* 分支2：`起始` $\xrightarrow{\text{ } \varepsilon \text{ }}$ `接受`

*(注：在纸质答题中，请将上述路径画成带箭头的状态机节点图（圆圈），终结符标在箭头上，非终结符写在矩形框或箭头上方表示子程序调用。)*

---

#### 3. 编写递归下降预测分析器

**分析：**
在编写代码前，先求出各非终结符的 $FIRST$ 集，以决定进入哪个分支：

* $FIRST(S) = \{ '(', 'a' \}$
* $FIRST(L) = FIRST(S) = \{ '(', 'a' \}$
* $FIRST(L') = \{ ',', \varepsilon \}$

这里假设存在全局变量 `lookahead` 指向当前输入符号，以及 `match(token)` 函数用于匹配终结符并使输入指针前进。

**解答（C语言风格伪代码）：**

```c
// 匹配函数
void match(char expectedToken) {
    if (lookahead == expectedToken) {
        lookahead = nextToken(); // 读取下一个字符
    } else {
        error(); // 报错
    }
}

// S 的分析过程
void S() {
    if (lookahead == '(') {
        match('(');
        L();
        match(')');
    } else if (lookahead == 'a') {
        match('a');
    } else {
        error();
    }
}

// L 的分析过程
void L() {
    // 因为 FIRST(L) = { '(', 'a' }，无条件调用 S() 和 Lprime() 
    // 若遇到不匹配的情况，会在 S() 中报错
    S();
    Lprime();
}

// L' 的分析过程
void Lprime() {
    if (lookahead == ',') {
        match(',');
        S();
        Lprime();
    } else {
        // 空产生式 (ε) 分支
        // 当前 lookahead 应该是 ')'，此处什么也不做，直接返回
    }
}
```

**分析：**
我们将严格追踪指针和函数的调用层级。为了清晰展示嵌套关系，我采用缩进表示调用的深度。

**解答：**
对于输入串 `( a , ( a , a ) )`，递归下降分析的过程调用序列如下：

│       │   ├── match('(')        // 匹配 '('，指针移向 'a'
│       │   ├── 调用 L()

│       │   │   └── 调用 Lprime() // lookahead = ','
│       │   │       ├── match(',')// 匹配 ','，指针移向 'a'

### 一、 题目复述与翻译

**英文原题：**

> **Exercise 4.2**
> Consider the context-free grammar
> $S \to a S b S \mid b S a S \mid \varepsilon$
> Can you construct a predictive parser for the grammar? and why?

**中文翻译：**

> **练习 4.2**
> 考虑以下上下文无关文法：
> $S \to a S b S \mid b S a S \mid \varepsilon$
> 你能为该文法构造一个预测分析器吗？为什么？

---

### 二、 详细解答

**结论：**
**不能（No）。** 我们无法为该文法构造一个（确定的）预测分析器。

**原因与过程分析：**
要为一个文法构造无回溯的递归下降预测分析器（即 LL(1) 分析器），该文法必须严格满足 **LL(1) 文法** 的条件。我们可以通过计算 `FIRST` 集和 `FOLLOW` 集，并检查是否存在冲突来证明。

#### 步骤 1：列出候选产生式

非终结符 $S$ 有三个候选产生式：

1. $S \to a S b S$
2. $S \to b S a S$
3. $S \to \varepsilon$

#### 步骤 2：计算 FIRST 集

根据产生式右部的第一个符号，可以轻易得出各候选式的 FIRST 集：

* $FIRST(a S b S) = \{ a \}$
* $FIRST(b S a S) = \{ b \}$
* $FIRST(\varepsilon) = \{ \varepsilon \}$

#### 步骤 3：计算 FOLLOW 集

我们需要找出在推导过程中，可能紧跟在非终结符 $S$ 后面的终结符集合：

1. $S$ 是文法的开始符号，因此输入结束符 `$` 必须加入 FOLLOW 集中：$\$ \in FOLLOW(S)$。
2. 观察产生式 $S \to a S b S$，第一个 $S$ 的后面紧跟的是终结符 $b$，因此 $b \in FOLLOW(S)$。
3. 观察产生式 $S \to b S a S$，第一个 $S$ 的后面紧跟的是终结符 $a$，因此 $a \in FOLLOW(S)$。

综上所得：**$FOLLOW(S) = \{ a, b, \$ \}$**

#### 步骤 4：检查 LL(1) 判定条件（构造预测分析表）

LL(1) 文法有一个核心判定定理：如果非终结符 $S$ 能够推导出空串 $\varepsilon$（即含有 $S \to \varepsilon$ 产生式），那么它的**其他候选式的 FIRST 集**必须与**该非终结符的 FOLLOW 集**互不相交（交集为空）。

我们来检查本题的情况：

* $FIRST(a S b S) \cap FOLLOW(S) = \{ a \} \cap \{ a, b, \$ \} = \mathbf{\{ a \}} \neq \emptyset$
* $FIRST(b S a S) \cap FOLLOW(S) = \{ b \} \cap \{ a, b, \$ \} = \mathbf{\{ b \}} \neq \emptyset$

#### 步骤 5：得出结论

因为交集不为空，如果在预测分析过程中栈顶是 $S$：

* 当面临的输入符号是 **`a`** 时，分析器会产生**多重入口冲突**：它既不知道是该选择 $S \to a S b S$ 进行匹配，还是该选择 $S \to \varepsilon$ （因为变成空串后，后续符号刚好也能匹配 `a`）。
* 当面临的输入符号是 **`b`** 时，同样会在 $S \to b S a S$ 和 $S \to \varepsilon$ 之间产生冲突。



* 因为 **$b \in FIRST(bSaS)$**，分析器想选 **$S \to b S a S$**
* 因为 **$b \in FOLLOW(S)$**，分析器想选 **$S \to \varepsilon$**

**补充说明：**
从更深层次的编译原理知识来看，这个文法实际上是一个**二义性文法**（它用于生成 $a$ 和 $b$ 数量相等的字符串，例如对于输入串 `abab`，它可以画出两棵完全不同的语法树）。而**任何二义性文法都不可能是 LL(1) 文法**，因此绝对无法为其构造确定的预测分析器。

### 一、 题目复述与翻译

**英文原题：**

> **Exercise 4.3**
> Compute the FIRST and FOLLOW for the start symbol of the following grammar
> $S \to S S + \mid S S * \mid a$

**中文翻译：**

> **练习 4.3**
> 计算以下文法开始符号（$S$）的 FIRST 集和 FOLLOW 集：
> $S \to S S + \mid S S * \mid a$

*(注：这是一个非常经典的后缀表达式文法，比如它可以推导出 `a a +` 这样的句子)*

---

### 二、 详细解答与步骤剖析

我们要计算的是非终结符 $S$ 的 $FIRST(S)$ 和 $FOLLOW(S)$。

#### 1. 求 FIRST(S)

$FIRST$ 集求的是从 $S$ 开始推导，最终得到的字符串里**第一个出现**的终结符。

观察 $S$ 的三个产生式：

1. $S \to a$：显然，以 $a$ 开头，所以 $a \in FIRST(S)$。
2. $S \to S S +$ 和 $S \to S S *$：这两个产生式是**左递归**的（第一个符号又是 $S$ 自己）。这意味着为了让推导终结（不能无限递归下去），最左边的这个 $S$ 最终必须被替换成终结符，而它唯一能替换成终结符的途径就是使用 $S \to a$。
3. $S$ 无法推导出空串 $\varepsilon$。

**结论：** 无论怎么推导，句子的最开头必定是 $a$。
**结果：** **$FIRST(S) = \{ a \}$**

---

#### 2. 求 FOLLOW(S)

现在我们用上一回讲的“三条黄金定律”来找谁能排在 $S$ 后面。

* **定律一（大 BOSS 兜底）：**
  $S$ 是文法的开始符号，所以无条件把结束符 `$` 加入集合。
  👉 目前：$FOLLOW(S) = \{ \$ \}$
* **定律二（看右边，找邻居）：**
  去产生式右边寻找 $S$ 的身影。我们在 $S \to S S +$ 和 $S \to S S *$ 中找到了它。
  为了看得更清楚，我们给这两个 $S$ 标上序号，写成 $S \to S_1 S_2 +$ 和 $S \to S_1 S_2 *$：
* **看 $S_1$ 的后面：**
  $S_1$ 后面跟着 $S_2$（非终结符）。根据定律，我们要把 $FIRST(S_2)$ 加入集合。
  因为 $FIRST(S) = \{a\}$，所以把 $a$ 加进去。
  👉 目前：$FOLLOW(S) = \{ \$, a \}$
* **看 $S_2$ 的后面：**
  在 $S \to S S +$ 中，$S_2$ 后面紧跟着终结符 `+`，所以把 `+` 加进去。
  在 $S \to S S *$ 中，$S_2$ 后面紧跟着终结符 `*`，所以把 `*` 加进去。
  👉 目前：$FOLLOW(S) = \{ \$, a, +, * \}$
* **定律三（找左边借靠山）：**
  这两个产生式最右边都是终结符（`+` 或 `*`），没有任何一个 $S$ 暴露在产生式的最末尾。因此不需要找左边借靠山。

---

### 三、 最终答案

综上所述，该文法开始符号 $S$ 的计算结果为：

* **$FIRST(S) = \{ a \}$**
* **$FOLLOW(S) = \{ a, +, *, \$ \}$**

### 第二部分：Exercise 5.2 解析

#### 1. 题目翻译与要求

**题目：**
给定以下文法：
$A \to B \mid B C$
$B \to a B \mid \varepsilon$
$C \to a b$

* **要求 1：** 对文法提取左公因子（Left factor）。
* **要求 2：** 提取左公因子后，该文法是 LL(1) 文法吗？或者是 LL(k) 文法吗？为什么？（提示：你可以尝试输入字符串 `ab`）。

#### 2. 解答步骤

**第一步：提取左公因子**
观察第一条产生式 $A \to B \mid B C$，它们有共同的前缀 $B$。提取左公因子后得到的新文法如下：

* $A \to B A'$
* $A' \to \varepsilon \mid C$
* $B \to a B \mid \varepsilon$
* $C \to a b$

**第二步：分析是否为 LL(1) 及其原因**
**结论：提取后依然不是 LL(1) 文法。**

*原因（冲突分析）：*
我们来看非终结符 $B$ 的产生式：$B \to a B \mid \varepsilon$

* $FIRST(aB) = \{ a \}$
* 要求 $FOLLOW(B)$：从 $A \to B A'$ 可以看出 $B$ 后面跟着 $A'$。而 $A'$ 可推导出 $C$，且 $C \to a b$，因此 $A'$ 可以以 `a` 开头；同时 $A'$ 也可推导为 $\varepsilon$，此时 $B$ 暴露在末尾，吸收 $FOLLOW(A)$ 即 `$`。所以 **$FOLLOW(B) = \{ a, \$ \}$**。
* 检查 LL(1) 的无冲突条件：
  $FIRST(aB) \cap FOLLOW(B) = \{ a \} \cap \{ a, \$ \} = \mathbf{\{ a \} \neq \emptyset}$。
  由于交集不为空，当栈顶为 $B$ 且面临输入字符 `a` 时，分析器不知道该选 $B \to aB$ 还是让 $B \to \varepsilon$ 隐身。因此不是 LL(1) 文法。

**第三步：分析是否为 LL(k) 及其原因**
**结论：它是一个 LL(2) 文法（因此属于 LL(k) 文法范畴）。**

*原因（结合提示输入 `ab` 说明）：*
当输入字符串为 `ab` 时，假设我们栈顶是 $B$，遇到第一个输入字符 `a`：

* 如果你**只往前看 1 个字符**（LL(1)）：你看到的是 `a`。你不知道它是属于 $B$（如 $B \to aB$）还是属于 $C$（通过 $B \to \varepsilon$ 且 $C \to ab$），陷入死锁。
* 如果你**往前看 2 个字符**（LL(2)）：你看到的是 `ab`。
* 如果我们选择 $B \to a B$，那么解析出来的串必定以 `aa` 或者 `a$` 开头。这和当前的 `ab` 不匹配。
* 如果我们选择 $B \to \varepsilon$，那么后续交给 $A' \to C \to ab$，刚好能完美匹配 `ab`。

从理论上看，对于产生式 $B \to a B \mid \varepsilon$：

* 向前看 2 个字符，选择 $B \to aB$ 产生的前缀集合（$FIRST_2$）为 **$\{ aa, a\$ \}$**。
* 选择 $B \to \varepsilon$ 产生的前缀集合（即 $FOLLOW(B)$ 前缀）为 **$\{ ab, \$ \}$**。
* 这两个集合的交集为空（$\{ aa, a\$ \} \cap \{ ab, \$ \} = \emptyset$）。
  因此，只要向前多看一个字符（共看2个）就能完全消除冲突。所以它是 LL(2) 文法。
